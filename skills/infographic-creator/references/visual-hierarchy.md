# Visual Hierarchy — Application Rules

Opinionated rules for controlling visual hierarchy in infographic design.

## Focus and Emphasis
- **10% rule:** Highlight at most 10% of the visual surface. Over-highlighting makes everything equally loud.
- De-emphasize supporting elements (axes, secondary data, reference lines) in light grey.
- Make the single most important number in each panel physically dominant.

## Reading Order
- Top-left placement for the key insight (Z-pattern reading).
- Structure panels in a clear top-to-bottom or left-to-right narrative flow.
- Use size, color, and position to signal the intended reading sequence.

## Labeling and Grouping
- Place data labels directly beside their marks — no separate legends when ≤5 items.
- Match label color to mark color for instant association.
- Use proximity to signal which elements belong together.
- Remove unnecessary borders and boxes — closure handles the rest.

## Layout
- Left-justify text. No center alignment. No diagonal elements.
- Use white space as a design element — generous margins draw attention to content.

## Validation: "Eyes Drawn" Test
Look away, look back. If gaze doesn't hit the intended focal point, adjust color, size, or layout and re-check.
