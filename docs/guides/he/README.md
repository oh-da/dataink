## לפני שמתחילים

מתקינים את הפלאגין פעם אחת, בתוך Claude Code:

```
/plugin marketplace add oh-da/dataink
/plugin install dataink@dataink
```

זהו. לא חייבים לזכור את הפקודות שבמדריכים — מספיק לתאר מה אתם רוצים ("תכין
לי גרף ממספרי המכירות האלה") ו-Claude יבחר את היכולת הנכונה לבד. הפקודות רק
הופכות את הבחירה למפורשת.

## הרעיון האחד שמאחורי הכול

כל יכולת כאן מתחילה מאותה שאלה: **מי הולך להסתכל על זה, ומה הוא אמור לעשות
אחרי שהסתכל?** אם אתם יודעים לענות על זה במשפט אחד — כל המדריכים נהיים קלים
יותר. אם לא — כתבו את זה בפרומפט, והיכולת תעזור לכם לברר את זה קודם.
