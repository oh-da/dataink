# גרפים בעברית (טקסט RTL)

**הבעיה:** בקשו מרוב כלי ה-AI גרף בעברית, והתוויות יוצאות הפוכות כמו במראה —
"תל אביב" הופך ל"ביבא לת". הקוד נראה תקין לגמרי; רק התמונה שבורה, אז אף אחד
לא שם לב עד שזה כבר על שקף מול אנשים שקוראים עברית.

**הכלל של DataInk:** רק ה*טקסט* הוא מימין לשמאל. הגרף עצמו נשאר משמאל
לימין — העמודות, סדר הקטגוריות, ציר הזמן והמספרים — כי מספרים נכתבים משמאל
לימין גם בעברית. שום דבר לא מתהפך; רק הכותרת עוברת לצד ימין, שם מתחילה
הקריאה בעברית.

## נסו עכשיו (העתיקו ושנו)

```
/dataink:data-visualization צור גרף עמודות של מכירות לפי עיר: תל אביב 61,
ירושלים 48, חיפה 39, באר שבע 27. תל אביב היא הסיפור.
```

## מה יקרה

1. Claude יזהה את העברית ויבדוק איך הכלי שבו אתם מציירים מתמודד איתה — וזה
   באמת שונה בין ספריות *ואפילו בין גרסאות*. matplotlib ישן מ-3.11 הופך
   עברית אלא אם מעבדים את הטקסט מראש; 3.11 ומעלה מסתדר לבד, ושם דווקא
   העיבוד המוקדם הוא זה ש*יוצר* את הבלגן. הפלאגין כולל בודק קטן
   (`check_rtl.py`) שמדפיס את הצעד הנכון לסביבה שלכם — שום דבר לא מנוחש.
2. גרפים מבוססי דפדפן (plotly, HTML) מקבלים את הטקסט כמו שהוא — דפדפנים
   מטפלים בעברית נכון בעצמם.
3. הכותרת מתיישרת לקצה הימני. העמודות, הצירים והמספרים נשארים בדיוק איפה
   שהיו בגרף באנגלית.
4. לפני סיום, Claude מרנדר תמונת בדיקה וקורא תווית אחת בחזרה — כי טקסט
   הפוך בלתי-נראה בקוד.

## איך יודעים שזה עבד

- בוחרים מילה אחת — שם של עיר — וקוראים אותה בתמונה הסופית, אות-אות.
  נכון: ירושלים. שבור: םילשורי.
- העמודות רצות משמאל לימין ומספרי הציר נקראים רגיל.
- הכותרת יושבת למעלה מימין.

## אם בכל זאת קיבלתם טקסט הפוך

הריצו את יכולת הבדיקה על התמונה ("תבדוק את הגרף הזה — התוויות בעברית").
עברית הפוכה היא שם ממצא "חובה לתקן", עם צעדי התיקון המדויקים לגרסת הספרייה
שלכם.
