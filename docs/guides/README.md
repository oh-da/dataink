# DataInk Beginner Guides

Plain-English guides to the six DataInk skills. No design experience needed —
each guide gives you one realistic situation, a prompt you can copy-paste, and
a simple way to check you got a good result.

## Which guide do I need?

| Your situation | Guide |
|---|---|
| "I have numbers and I need a chart" | [Making a chart](data-visualization.md) |
| "People need to look up exact numbers" | [Making a table](table-design.md) |
| "I need one screen that shows how things are going" | [Making a dashboard](dashboard-design.md) |
| "I already have a chart — is it any good?" | [Checking a chart](visualization-review.md) |
| "I need to convince people in a presentation" | [Telling the story](data-storyteller.md) |
| "I need a good-looking one-pager that sums it all up" | [Making an infographic](infographic-creator.md) |

## Before you start

Install the plugin once, inside Claude Code:

```
/plugin marketplace add oh-da/dataink
/plugin install dataink@dataink
```

That's it. You don't even have to remember the commands in these guides —
just describe what you want ("make me a chart of these sales numbers") and
Claude picks the right skill automatically. The commands only make it explicit.

## The one idea behind everything

Every skill here starts from the same question: **who is going to look at
this, and what should they do after looking?** If you can answer that in one
sentence, every guide below gets easier. If you can't, say so in your prompt —
the skills will help you figure it out first.
